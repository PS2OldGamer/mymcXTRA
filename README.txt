                                 mymcXTRA v1.2.0
                       Modern PlayStation 2 Memory Card Suite
===============================================================================

mymcXTRA is a modernized, standalone freeware utility designed for comprehensive 
PlayStation 2 memory card file architecture management, backup translations, 
and responsive 3D asset viewing.

FEATURES
-------------------------------------------------------------------------------
* Core-Profile 3D Viewport: Full real-time multi-frame save icon animations, 
  alpha-blended texture masks, and true camera-space frontal depth lighting.
* Complete Mouse Interaction: Fluid drag tracking with tight, local orbit rotations.
* Universal Format Translation: Clean-room bidirectional conversion across 
  PCSX2 (.ps2), MemCard PRO2 (.mc2), SD2PSX (.mcd), and OPL raw sectors (.bin).
* Thread-Safe Environment: Pure memory-buffered operations that eliminate 
  unwanted Windows file-handle access collisions and directory errors.
* Aesthetic Upgrade: Modern minimalist toolbar layouts supporting true alpha 
  channel transparency.

HERITAGE & LICENSING
-------------------------------------------------------------------------------

All extended graphical pipelines, real-time 3D interpolators, multi-format 
hardware translation layers, and memory buffer operations have been entirely
